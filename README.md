# Drum Machine
This web application is a step sequencer drum machine that generates synthesized percussion sounds.

## Description
The application uses the browser web audio api to create oscillator nodes triggered by a timed interval loop. Users toggle steps in a grid to build custom rhythmic patterns played back at a chosen tempo.

## Capabilities
- Interactive step grid interface
- Adjustable tempo slider
- Synthesized audio triggers
- Play stop and clear controls

## Structure
- `index.html`: Main markup structure
- `style.css`: Styles and theme variables
- `script.js`: Audio synthesis and sequencer logic

## Execution
Open `index.html` in a browser. No install or build step.
